书音 BookTone v1.33.0

为「读完一本书」设计的一切

从搜到存，每一步都可编程、可扩展、可观测。

聚合搜索

59 个搜索源并发查询，按关键词覆盖度、字数、更新时间、站点权重、完结状态五信号排序，并给出可解释的匹配等级（精确 / 前缀 / 包含 / 部分）与相关度分数；同书多源合并、来源胶囊、最近搜索缓存（可选落盘，重启后仍可复用）。结果流式到达（首屏约 0.2 秒），桌面端逐源显示进度、失败数与耗时，新搜索自动取消旧请求。

队列与断点续传

站点级并发调度、章节级断点续传、传输类失败自动重试、进度实时可见；处理与导出阶段同样可取消。

多格式导出

TXT / EPUB / HTML 一步到位：原子写入、分卷去重、章节净化，随时对已下载书目重新导出。

追更

关注列表定时自检新章节，发现更新即可一键入队；全量检查并发受控，慢站不拖快站。

音乐下载

28 个平台一键聚合搜索，同一首歌合并成一行并标出来源；Hi-Res 到标准音质五档可选，标签/封面/歌词嵌入，歌单（.m3u8）导出，平台连通性健康检查。搜索、下载、账号、依赖与 CDM 能力一屏可见，缺账号时桌面端直接引导到设置。

处理器管线

广告净化、简繁转换、OCR 图片章节、机翻润色——以插件形式串在下载与导出之间，JSON 规则书源免代码接入新站点。

存储备份与 dry-run

SQLite 在线备份/恢复：WAL 一致、完整性校验，恢复覆盖前自动留 .bak；clean 与 storage --clean 支持 --dry-run，先看文件数与字节数，零删除确认后再动手。

桌面无障碍

跳过导航、方向键操作的标签页、模态焦点陷阱与焦点归还、轮询不抢焦点、toast 实时播报、进度条语义——用键盘和读屏也能从搜索走到导出。

内置更新

桌面、CLI 与安卓每 24 小时最多读取一次更新清单（latest.json）；新版本后台下载并校验 SHA-256，Windows 退出即装（便携版替换当前目录），安卓确认一次即可。更新就绪状态与版本绑定，静默更新后安装器自动重启。

一套服务层，四个入口

同一份配置、同一个下载队列、同一个历史库——换端不换数据。

CLI

novel-cli

15 个子命令：搜索、浏览榜单分类、下载、批量、追更、导出、登录、诊断；export --out 指定输出、单行 JSON、fish 补全，管道与脚本全兼容。

REST API

novel-api

FastAPI 本地服务，22+ 端点、SSE 流式、Python SDK，给第三方软件当下载后端。

Windows 桌面

novel-desktop

原生窗口、藏青与暖橙双主题、实时进度与健康检查面板，打包成独立 exe。

Android

Gradle

Kotlin + Compose 原生客户端，Material 3，DownloadManager 落盘；可选「独立引擎」——Chaquopy 内嵌 Python 3.12，84 站点 / 59 搜索源与音乐平台全部跑在手机本地（环回 API，无需电脑）。任务快照持久化，进程被杀后重启可恢复「已中断」任务；音乐下载路径同样保留，重启后仍可导出歌单。关闭开关则仍遥控电脑端 novel-api。

校验你的下载

每个版本都附 SHA256SUMS.txt，逐行列出文件名与 SHA-256；自动更新读取的 latest.json 携带同一批校验值。对下载好的文件算一次哈希，与清单中对应行比对：一致即说明文件完整、未被改动。

Windows（PowerShell）

Get-FileHash .\NovelDownloader-setup-*.exe -Algorithm SHA256

macOS / Linux

shasum -a 256 NovelDownloader-*.zip   # macOS
sha256sum NovelDownloader-*.zip       # Linux

SHA256SUMS.txt → latest.json →

校验值能发现下载损坏或被替换的文件，但它还不是签名：清单签名机制已内置但尚未启用，校验值本身不能证明发布者身份。请只从本页的 Releases 链接或官方 GitHub 仓库下载。

常见问题

最高频的几个问题，先答为敬。

免费吗？能跑在哪里？

完全开源免费（Apache-2.0）。任何能跑 Python 3.11+ 的系统都行——Windows、macOS、Linux；Windows 打包版连 Python 都不需要。

支持哪些站点？

内置 84 个下载站点、59 个搜索源（仓库内附完整清单），并支持 JSON 规则书源免代码新增站点；番茄额外支持排行榜与男/女频 37 个分类浏览。站点列表持续更新。

合规吗？

项目仅供学习与研究。请自行遵守目标站点 robots.txt 与当地法规，勿用于商业用途。

会收集我的数据吗？

无遥测、无账号。书籍、音乐、配置、日志全部留在本机；可选的 REST API 默认只监听 127.0.0.1。

桌面端怎么更新？

应用每 24 小时最多读取一次更新清单（latest.json）；发现新版本后台自动下载并校验，退出应用时自动安装——不需要逐层点确认（便携版替换当前目录）。离线时静默，不打扰。

更新机制是怎么工作的？

CLI、API、桌面端同源于同一个 pip 包——pip install -U novel-downloader（或重跑一键安装脚本）即升到最新版，Windows 桌面端另有每 24 小时最多一次的更新清单（latest.json）自查。站点解析修复与新书源随常规版本发布，普通升级即可修复大多数失效站点——你的配置、队列与已下载书目原样保留。

某个站点失效了怎么办？

站点改版不可避免。带站点名和报错信息提 Issue 即可；解析层故障隔离，单站失效不影响其他站点。

独立引擎和远程模式有什么区别？

远程模式：手机只是遥控器——搜索与下载实际跑在电脑端 novel-api 上，App 里填电脑的 API 地址即可。独立引擎：App 经 Chaquopy 内嵌 Python 3.12，把整套服务层跑在手机本地（环回 API），无需电脑。数据跟着引擎走：远程模式留在电脑，独立模式留在手机。独立模式下书籍与音乐都在本地运行，APK 因内嵌运行时约 68 MB。设置里的一个开关即可随时切换两种模式。
