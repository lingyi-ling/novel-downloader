Novel Downloader v1.2.0

为「读完一本书」设计的一切

从搜到存，每一步都可编程、可扩展、可观测。

聚合搜索

59 个搜索源并发查询，按关键词覆盖度、字数、更新时间、站点权重五信号智能排序；同书多源自动合并，最近搜索缓存，秒级响应。

队列与断点续传

站点级并发调度、章节级断点续传、传输类失败自动重试、进度实时可见；处理与导出阶段同样可取消。

多格式导出

TXT / EPUB / HTML 一步到位：原子写入、分卷去重、章节净化，随时对已下载书目重新导出。

追更

关注列表定时自检新章节，发现更新即可一键入队；全量检查并发受控，慢站不拖快站。

音乐下载

25 个平台聚合搜索，Hi-Res 到标准音质五档可选，标签/封面/歌词嵌入，播放列表导出，平台连通性健康检查。

处理器管线

广告净化、简繁转换、OCR 视频章节、机翻润色——以插件形式串在下载与导出之间，JSON 规则书源免代码接入新站点。

一套服务层，四个入口

同一份配置、同一个下载队列、同一个历史库——换端不换数据。

CLI

novel-cli

12 个子命令：搜索、下载、追更、导出、登录、诊断，管道与脚本全兼容。

REST API

novel-api

FastAPI 本地服务，22+ 端点、SSE 流式、Python SDK，给第三方软件当下载后端。

Windows 桌面

novel-desktop

原生窗口、暖纸双主题、实时进度与健康检查面板，打包成独立 exe。

Android

Gradle

Kotlin + Compose 原生客户端，Material 3，直连本地 API，DownloadManager 落盘。

三十秒上手

选你的入口，复制，运行。

# Windows 一键安装（PowerShell，无需管理员）
irm https://raw.githubusercontent.com/lingyi-ling/novel-downloader/main/bin/install.ps1 | iex

# Linux / macOS 一键安装
bash <(curl -sSL https://raw.githubusercontent.com/lingyi-ling/novel-downloader/main/bin/install.sh)

# —— 或者用 pip ——
pip install -U novel-downloader

# 聚合搜索
novel-cli search "凡人修仙传"

# 一键下载（支持断点续传）
novel-cli download --site qidian 107580

# 追更 + 音乐
novel-cli follow add --site qidian 107580
novel-cli music search "晴天" --platform netease
# 启动本地 REST 服务（127.0.0.1:8081）
pip install "novel-downloader[api]"
novel-api

# 搜索
curl -X POST http://127.0.0.1:8081/api/v1/search \
  -H "Content-Type: application/json" \
  -d '{"keyword": "凡人修仙传"}'

# 入队下载
curl -X POST http://127.0.0.1:8081/api/v1/tasks \
  -H "Content-Type: application/json" \
  -d '{"site": "qidian", "book_id": "107580", "title": "凡人修仙传"}'
# 安装（含 pywebview 桌面壳）
pip install -U novel-downloader

# 启动图形界面
novel-desktop

# 暖纸色双主题 · 实时下载进度 · 平台健康检查
# Ctrl+1-5 切换五个页面
# 从源码构建（JDK 17 + Android SDK 35）
git clone https://github.com/lingyi-ling/novel-downloader
cd novel-downloader/android
./gradlew assembleDebug

常见问题

最高频的几个问题，先答为敬。

免费吗？能跑在哪里？

完全开源免费（Apache-2.0）。任何能跑 Python 3.11+ 的系统都行——Windows、macOS、Linux；Windows 打包版连 Python 都不需要。

支持哪些站点？

内置 84 个下载站点、59 个搜索源（仓库内附完整清单），并支持 JSON 规则书源免代码新增站点；站点列表持续更新。

合规吗？

项目仅供学习与研究。请自行遵守目标站点 robots.txt 与当地法规，勿用于商业用途。

会收集我的数据吗？

无遥测、无账号。书籍、音乐、配置、日志全部留在本机；可选的 REST API 默认只监听 127.0.0.1。

桌面端怎么更新？

应用每 24 小时检查一次 GitHub Releases，发现新版本会弹出可点击的提示；离线时静默，不打扰。

某个站点失效了怎么办？

站点改版不可避免。带站点名和报错信息提 Issue 即可；解析层故障隔离，单站失效不影响其他站点。
