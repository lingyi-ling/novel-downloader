v1.43.0

2026-11-25

官网更新日志页、桌面诊断信息与 API 运行指标。

  • 官网新增中英更新日志页，导航、页脚与 404 页均可进入，并纳入 sitemap。
  • 桌面设置页可复制诊断信息（版本、系统、数据/日志路径、关键偏好），用户名脱敏且不含凭据。
  • GET /api/v1/metrics 返回按状态/方法分类的请求数、拒绝计数、SSE 活跃/峰值与运行时长；受 token 保护、no-store，且不记录路径或关键词。

v1.42.0

2026-11-25

桌面取消更新下载、embedded 缓存策略与规则模糊测试修复。

  • 桌面更新条新增「取消」，分块与退避阶段都能中断，已下载的 .part 保留供续传。
  • 完成与取消竞态时完成优先；cancel_update_download 有界等待并发布 cancelled 状态。
  • REST 与 embedded 共用同一缓存策略：参考端点 private, max-age=60，其余成功响应与全部错误 no-store，304 沿用对应指令。
  • 规则引擎把模糊测试暴露的裸异常（孤立代理对、非法编码、标量结果、深层列表）统一归为 RuleError 或安全值。
  • 测试隔离：桌面后台更新检查不再启动真实下载线程污染后续用例。

v1.41.1

2026-11-25

磁盘失败清理、API 阻塞池与 Android SAF 授权撤销。

  • 磁盘满或只读时，原子写失败后会清理只读的 .tmp（此前在 Windows 上永久残留）；歌单写入补 fsync。
  • 音乐搜索、下载与任务改用专用 8 线程有界池，连续超时或断开不再无限新建 OS 线程。
  • 排队中的超时调用在开始前取消，同时保留 contextvars 中的请求 ID。
  • Android SAF：写入与 close 阶段的授权撤销、文档删除和 ENOSPC 正确分类并删除半成品，close 失败不再误报为网络错误。
  • 失效目录自动重建；取消后不再出现幽灵 100% 进度。

v1.41.0

2026-11-25

API gzip 压缩、桌面最近搜索与 CLI 表格健壮性。

  • /api/v1 JSON 响应在客户端允许且不小于 1 KiB 时 gzip 压缩；SSE、下载、304 与 HEAD 不压缩。
  • 所有响应带 Vary: Accept-Encoding；ETag 基于未压缩字节，gzip 与 identity 共用同一 ETag。
  • 桌面搜索框下显示最近 10 条搜索 chips，去重置顶，点击可按当前条件重搜，并提供清空入口。
  • 最近搜索保存在 desktop_prefs.json 的 search_history，不参与设置导出。
  • CLI 表格在 COLUMNS 极小时不再产生空表，单元格内的 ANSI/OSC 序列在排版前剥离。
  • 最近搜索 chips 的渲染纳入 XSS sink 清单，模板统一转义。

v1.40.0

2026-11-24

Android 引擎容错、follow JSON 与配置/规则健壮性。

  • 新增 follow check --json，输出单行对象（ok/checked/changed/failed/invalid/books），--wait 与 --json 互斥。
  • Android 引擎启动状态机（STARTING/READY/FAILED/STOPPED + generation），8081 到 8084 端口回退与 15 秒健康探测。
  • 桌面自动下载幂等：并发或重复事件只下载一次，已下载文件复用前复验。
  • 配置中的超大整数与非法路径不再抛裸 OverflowError / ValueError，统一为带路径的配置问题。
  • 规则 JSON 正确解析链式下标 a[0][1]，深层嵌套与循环引用转为 RuleError。

v1.39.0

2026-11-22

桌面窗口重置、OpenAPI 文档质量与扫描/下载分类强化。

  • 桌面设置页新增「重置窗口位置与大小」，只删五个 window_* 偏好，当前窗口不移动、下次启动生效。
  • OpenAPI 补齐 servers、关键端点请求/响应示例、304 空体示例与 400/413/415/500/503/504 响应声明。
  • 密钥扫描新增 URL userinfo、Slack/Discord webhook 与 JWT 规则，未加引号的配置值按数据处理。
  • Android 下载失败补齐 ERROR_DEVICE_NOT_FOUND 文案与全部 COLUMN_REASON 分类。
  • provider 的 SecurityException 归为权限问题并回退系统 Downloads；HTTP 状态由 DownloadHttpException 携带。
