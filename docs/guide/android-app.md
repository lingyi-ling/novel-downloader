# Android 客户端

原生 Android App（Kotlin + Jetpack Compose），通过**本地 REST API** 与电脑端通信：
搜索小说、管理下载任务、浏览导出文件、下载多平台音乐。

## 前置条件

1. 电脑端启动 API 服务：

   ```bash
   # 仅本机使用（模拟器可访问 10.0.2.2）
   novel-api --port 8081

   # 真机访问：绑定局域网，并建议设置 token
   novel-api --host 0.0.0.0 --port 8081 --token <你的密钥>
   ```

2. 手机与电脑在同一局域网；Windows 防火墙放行 8081 端口。

## 安装 App

源码位于仓库 `android/` 目录：

```bash
cd android
./gradlew assembleDebug      # 生成 app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug       # 或直接安装到已连接设备
```

用 Android Studio 打开 `android/` 亦可直接 Sync 并运行。

### 正式签名包（Release）

Release 构建需要签名材料。在 `android/` 下创建 **git-ignored** 的
`keystore.properties`（模板见 `app/build.gradle.kts` 头部注释）：

```properties
storeFile=release.jks
storePassword=...
keyAlias=...
keyPassword=...
```

```bash
./gradlew assembleRelease    # 产出 app/build/outputs/apk/release/app-release.apk
```

密钥文件缺失或不完整时，Release 包会回退到 debug 签名（仅适合本机测试，
不能对外发布）。**`keystore.properties` 与密钥文件必须留在本地，切勿提交。**

## 运行单元测试

App 自带不依赖设备的 JVM 单元测试（API 客户端、追更排队逻辑、导航等）：

```bash
cd android
./gradlew testDebugUnitTest
```

## 首次配置

打开 App 右上角「设置」：

| 场景 | API 地址 |
| --- | --- |
| 模拟器访问电脑 | `http://10.0.2.2:8081/` |
| 真机访问电脑 | `http://<电脑局域网 IP>:8081/` |
| 独立模式（「独立引擎」开启） | 无需配置，自动使用本机 `http://127.0.0.1:8081/` |

API 设置了 token 时，把同一个值填入「API 密钥」。

## 功能

底部页签：**搜索 / 任务 / 历史 / 音乐 / 追更**。

- **搜索**：关键字搜索；站点多选（不勾选任何站点即搜索全部启用站点），可展开「高级筛选」按字数区间和更新时间过滤。结果一键加入下载队列，或点「追更」加入追更列表。
- **追更**：维护追更列表（列表 / 添加 / 移除）；点「检查更新」逐本搜索最新章节，发现新章节的条目可一键加入下载队列。
- **任务**：进行中 / 排队 / 完成分区展示，进度条与章节数，自动刷新（2 秒），可取消；失败、已取消和中断的任务可一键重试。
- **登录凭据请求**：站点需要登录（账号/Cookie）而本地又没有可用凭据时，任务会挂起并在任务页顶部出现「登录凭据请求」卡片；点「提供凭据」按字段填写（密码/Cookie 类字段输入掩码显示，必填校验、预填值回带），提交后任务自动继续。
- **历史**：导出文件列表，点击后保存到系统「下载」（Downloads）目录，或保存到设置中选择的自定义目录（见下文）。
- **音乐**：选择平台、搜索歌曲、多选后创建下载任务并显示进度。

## 搜索与筛选

### 站点选择

「搜索站点」字段打开的是多选对话框，不是文本框：

- 勾选一个或多个站点后，只搜索这些站点。
- **一个都不勾选表示全部启用站点**，字段显示「全部站点」。
- 选择结果保存在本机，下次打开 App 仍然生效。

### 高级筛选

搜索框下方的「高级筛选」可展开可选条件：

| 条件 | 规则 |
| --- | --- |
| 最少字数 / 最多字数 | 可只填其中一个；必须是 `0`–`1000000000` 之间的整数 |
| 更新日期晚于 | 用日期选择器选 `YYYY-MM-DD`，**包含所选当天**；点右侧清除图标可取消 |

- **留空即不过滤**：三个条件都为空时，请求与没有筛选功能时完全一致。
- 输入不合法（非整数、负数、超过 10 亿，或最少字数大于最多字数）时，点「搜索」不会发出请求，并自动展开筛选面板显示对应错误。
- 筛选在排名之后执行（由电脑端 API 或独立引擎完成），只缩小结果集，不改变排序。启用字数条件后，未提供字数的条目会被丢弃；启用日期条件后，未提供更新日期的条目会被丢弃——这不是请求失败，「结果变少」通常就是这个原因。
- 「生效筛选：N 项」显示当前非空条件的数量，可一键「清空筛选」。切换页签、以及系统在后台回收进程后从最近任务恢复时，筛选内容都会保留。

## 下载目录与文件保存

「历史」页列出导出文件，点一下即开始保存。默认交给系统 DownloadManager 写入公共「下载」（Downloads）目录，通知栏可看到进度。

### 自定义下载目录（SAF）

在「设置 → 下载」点「选择目录」，通过系统文件选择器（SAF，`ACTION_OPEN_DOCUMENT_TREE`）授权一个目录：

- 文件写入所选目录下的 `NovelDL/` 子文件夹，不存在时自动创建。
- 同名文件不会覆盖，依次改为 `name (1).ext`、`name (2).ext` …（大小写不敏感）。
- 读/写授权用 `takePersistableUriPermission` 持久化，重启手机后仍然有效。
- 设置页会显示当前目标：「下载目录：<目录>（NovelDL 子目录）」或「下载目录：系统 Downloads」。

授权失效时（在系统设置中撤销、提供该目录的应用被卸载或更换、目录被删除或移走、备份恢复到另一台设备），设置页会显示「自定义下载目录不可用，请在设置中重新选择」，但保留原选择以便替换。此时在历史页下载会**自动回退到系统 Downloads**，并提示「自定义下载目录不可用，已改为保存到系统 Downloads」；授权在下载前和实际写入时各校验一次，因此不会把文件写到错误位置。

「恢复默认」会释放持久化权限并回到系统 Downloads。若目录可访问但无法创建文件（例如提供方报错），会直接提示保存失败，不会悄悄改存到别处。

!!! note "作用范围"
    自定义目录只影响「历史」页的下载。任务详情里下载导出文件仍走系统 DownloadManager 保存到系统 Downloads；音乐文件按下一节的方式保存。排查步骤见 [故障排查 § 自定义下载目录](./troubleshooting.md#51-saf)。

## 任务、通知与恢复

「任务」页每 2 秒自动刷新，也可下拉手动刷新；卡片展示进度、章节数，展开后可下载该任务的导出文件。

### 任务快照与中断恢复

电脑端 API（独立模式下是手机本地引擎）把任务保存在进程内存中，进程结束就会丢失。App 在本地另存一份任务快照，因此：

- App 被系统回收或重启后，「任务」页仍会显示之前的队列、进度和已完成记录，不会变成空白。
- 重启时仍在排队/执行的任务不可能还在运行，会被标记为「已中断」，并提示「应用重启导致任务中断，可点击重试继续下载」。
- 引擎有响应、但列表里已不再包含的进行中任务，也会被标记为「已中断」，而不是一直显示进行中。
- 失败、已取消和已中断的任务提供「重试」：用原来的站点、书籍 ID 和标题重新加入下载队列，成功后提示「已重新加入下载队列」。缺少站点或书籍 ID 的记录无法重试；同一任务在一次会话内只会重新入队一次，避免连点重复排队。

### 通知与点击定位

任务完成或失败时会发送系统通知；同一任务的通知原地更新，不会堆叠。

- Android 13+ 首次启动会请求「通知」权限（`POST_NOTIFICATIONS`）。拒绝后可在「设置 → 通知」查看状态，并点「打开通知设置」重新开启；通知被关闭时，任务结束会让任务页提示一次。
- **点通知会打开 App 并切到「任务」页，展开、短暂高亮并滚动到对应任务。** 本地快照里已有该任务时会立即定位；否则等第一次刷新完成后再判断。
- 如果刷新后列表里已经没有被点通知的任务（例如已被清理），会停留在任务页并提示「该任务已不存在，可能已被清理」。通知来自没有有效任务 ID 的异常记录时，只打开「任务」页，不定位具体条目。

## 音乐与歌词

「音乐」页选择平台、搜索歌曲、多选后创建下载任务，页面显示进度和成功 / 跳过 / 失败数量。

- **独立模式**：下载完成后，App 通过系统 DownloadManager 把音频转存到公共「下载」目录。
- **远程模式**：文件保存在电脑端，App 只显示服务器上的路径，不会把音频拉到手机。
- **歌词**：音乐引擎默认开启歌词保存（`save_lyric`），会把歌词写成音频旁的 `<stem>.lrc`，有译文时另写 `<stem>.zh.lrc`。Android 客户端目前**只转存音频文件，不会把 `.lrc` 一起复制到系统 Downloads**：独立模式下歌词留在 App 私有的引擎目录，远程模式下留在电脑上。需要歌词文件时请用桌面端或 `novel-cli music download`。

## 内置更新检查

App 启动时会检查更新，**每 24 小时最多一次**（上一次检查的时间戳缓存在本机；系统时钟回拨时也会重新检查）。检查优先读取发布附带的更新清单 `latest.json`（稳定地址，不受 GitHub API 速率限制），清单不可用或不含安卓条目时才回退到 GitHub Releases API。

更新流程的约束：

1. 只接受 **HTTPS** 下载地址。
2. 资产必须带 **SHA-256**；缺失则拒绝下载——宁可让用户手动更新，也不安装无法校验的包。
3. 下载完成后复算 SHA-256；在拉起系统安装器**之前再校验一次**，防止文件在两次校验之间被替换。
4. 校验通过后把 APK 交给**系统安装器**，由用户确认安装；App 不会、也无法静默安装。

发布侧同样有门禁：`scripts/release.py` 在发布前用 `scripts/check_android_alignment.py` 校验正式 APK 的 zip 条目与各 `.so` 的 `PT_LOAD` 段对齐，未通过 **16 KB 页对齐**的包不会被发布——这是 Android 15+ 16 KB 页设备能正常加载原生库的前提。

## 独立引擎（无需电脑）

App 支持两种运行模式，可在设置页通过「独立引擎（无需电脑）」开关随时切换：

- **远程模式（默认，开关关闭）**：手机遥控电脑端 novel-api，搜索、下载等都在电脑上执行；电脑需运行 API 服务并与手机同处一个局域网，即上文描述的原有模式。
- **独立模式（开关开启）**：无需电脑，手机本地运行完整的下载引擎。APK 通过 Chaquopy 内嵌 Python 3.12 运行时（arm64-v8a + x86_64 双 ABI），把整个 novel_downloader 服务层打进包内；引擎启动后在本机环回地址 `http://127.0.0.1:8081/` 上提供与 novel-api 相同的 REST 接口。搜索、任务、历史、追更等全部功能都在手机上完成，数据、任务与历史也只保存在手机本地。

开关开启时，App 启动会先启动本地引擎，再初始化 API 客户端（API 地址自动固定为本机环回地址，无需配置，详见「首次配置」）；关闭开关即切回远程模式，重新连接电脑端 novel-api。

注意事项：

- **音乐**：独立模式已内置音乐引擎（requests / mutagen / Pillow / qrcode / websocket-client / m3u8 / emoji 等），可直接搜索、下载；文件先落到引擎目录，完成后由系统 DownloadManager 转存到公共「下载」目录。
- **APK 体积增大**：因打包 Python 运行时及其依赖（aiohttp、lxml、cssselect、pycryptodome、rich、platformdirs 等），APK 体积从约 12MB 增至约 68MB。
- 本地引擎仅绑定环回地址 `127.0.0.1`，只有 App 自身可以访问，局域网内其他设备无法连接。

## 安全说明

App 使用 HTTP 访问本地 API（`usesCleartextTraffic=true`）。只建议在可信局域网内使用；
若需跨网络访问，请通过 VPN（如 Tailscale）或在 API 前加一层 HTTPS 反向代理，并始终设置 token。
